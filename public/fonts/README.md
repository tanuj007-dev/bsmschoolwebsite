# Gotham font files

Place your licensed Gotham font files here so they load site-wide:

- **Gotham-Book.woff2** (or GothamBook.woff2) – regular weight (400)
- **Gotham-Bold.woff2** (or GothamBold.woff2) – bold weight (700)

If you use different filenames, update the `@font-face` paths in `app/globals.css` to match.

Until these files are added, the site will use the fallback font (Montserrat).
